## 결정 완료

### 구조 / 계정 / 권한

| # | 항목 | 결정 |
|---|---|---|
| A1 | 팀 구조 | **단일 팀.** 팀 선택, 팀 간 격리 없음 |
| A2 | 역할 | 관리자(정확히 1명) + 팀원. 슈퍼 관리자 없음 |
| A3 | 첫 관리자 | 최초 실행 시 환경변수(`INITIAL_ADMIN_ID`, `INITIAL_ADMIN_PASSWORD`)로 생성 |
| A4 | 계정 생성 | 관리자가 생성, 첫 로그인 시 비밀번호 변경 |
| A5 | 관리자 교체 | 관리자 위임. 위임하면 본인은 팀원이 됨. 관리자 계정은 비활성화 불가 |
| A6 | 관리자 잠금 복구 | 서버 명령으로 초기화 |
| A7 | 비공개 | **기능 없음.** 모든 업무 데이터는 팀 전체 공개 |
| A8 | 수정 권한 | 본인이 만든 것만. 관리자도 다른 사람의 업무 데이터는 수정 불가 |
| A9 | TODO 할당 | 불가. TODO는 본인 할 일 (작성자 = 수행자) |
| A10 | 통계 열람 | 본인 통계는 누구나, 팀원별 통계는 관리자만 |
| A11 | 계정 비활성화 | 로그인 불가, 데이터와 이름은 "(비활성)" 표시로 남음, 반복 TODO 중지, 예약 알림 취소 |
| A12 | 재활성화 시 반복 TODO | 자동 재개하지 않음 |
| A13 | 비밀번호 정책 | 8자 이상, 5회 실패 시 잠금. 관리자가 해제 |
| A14 | 인증 방식 | 서버 세션 (Spring Session). 매 요청마다 계정 활성 여부 확인 |

### TODO

| # | 항목 | 결정 |
|---|---|---|
| T1 | TODO 주기 | 기간 TODO(일/주/월) + 반복 TODO |
| T2 | 주간 기간 | 월~일 (통계만 월~금) |
| T3 | 알림 | TODO마다 직접 지정, 1개 |
| T4 | 유형 | 관리자가 관리. 삭제하면 해당 TODO의 유형은 "없음" |
| T5 | 상태 | 미완료/완료만. 하위 TODO 없음 |
| T6 | 이월 | 기간이 지난 미완료 TODO를 오늘/이번 주로 이월. 원래 기간과 이월 횟수 기록 |
| T7 | 완료 취소, 기간 변경 | 둘 다 허용 |
| T8 | 반복 TODO | 생성되는 TODO는 일 단위. 매월 31일처럼 없는 날은 말일. 평일 반복은 공휴일 제외 |
| T9 | 반복 소급 | 서버가 꺼져 있던 날의 반복 TODO는 최대 7일까지 소급 생성 (알림은 미발송) |
| T10 | 반복 규칙 수정 | 이후 생성분부터 반영 |

### 화면 / 점심 / 기술

| # | 항목 | 결정 |
|---|---|---|
| U1 | 대시보드 | 오늘 할 일, 이번 주 할 일, 오늘 부재자, 다가오는 배포. 지연 TODO 이월 안내 |
