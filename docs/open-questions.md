# 결정 사항과 미결 항목

> 답이 정해지면 해당 문서와 .feature를 수정하고 "결정 완료"로 옮깁니다.

## 결정 완료

### 권한 / 계정

| # | 항목 | 결정 |
|---|---|---|
| A0 | 팀 소속 | 한 사람이 여러 팀에 소속 가능. 역할과 활성 상태는 팀마다 따로 가짐 |
| A0-1 | 팀 이동 | 기능 없음. 슈퍼 관리자가 새 소속 추가 + 기존 소속 비활성화 |
| A0-2 | 비활성 소속 | 그 팀으로 로그인/전환 불가. 데이터와 이름은 남고 "(비활성)" 표시 |
| A0-3 | 계정 생성 | 슈퍼 관리자가 생성, 첫 로그인 시 비밀번호 변경 |
| A0-4 | 슈퍼 관리자 겸 팀원 | 별도 계정 사용. 슈퍼 관리자 계정은 팀 소속 불가 |
| A1 | 팀 관리자 수 | 팀당 최대 2명 (활성 기준) |
| A2 | 팀 관리자 권한 | 팀원 데이터는 조회만 |
| A3 | TODO 할당 | 불가. TODO는 본인 할 일 |
| A4 | 팀원 간 통계 열람 | 불가 (팀 관리자만 팀원별 통계 조회) |
| A5 | 비공개 열람 설정 | 팀별 설정, 기본값 꺼짐 |
| A7 | 비밀번호 정책 | 8자 이상, 5회 실패 시 잠금 |
| A8 | 소속 재활성화 시 반복 TODO | 자동 재개하지 않음 |

### 알림 / 점심 / 기술

| # | 항목 | 결정 |
|---|---|---|
| N0 | 놓친 알림 | 슬랙 발송 안 함, 알림함에 "미발송"으로 남김 |
| N1 | 슬랙 연동 방식 | **팀 관리자가 팀당 채널 1개 등록** (Incoming Webhook). 슬랙 미사용 팀은 알림함만 |
| N1-1 | 비공개 TODO 알림 | 채널로 보내지 않고 알림함에만 |
| N1-2 | 사람 구분 | 본인이 슬랙 멤버 ID를 등록하면 @멘션, 없으면 이름 표시 |
| N1-3 | 채널 발송 종류 | 팀 관리자가 알림 종류별로 채널 발송 켜기/끄기 |
| N1-4 | 주간 통계 발송 | 팀 합계만 채널로 발송 (비공개 TODO 제외). 개인 통계는 화면에서만 |
| N1-5 | 연차 알림 | 전날 17:00 팀 채널로 "내일 OOO 연차" 공유 |
| N2 | 알림 종류별 켜기/끄기 | 가능 |
| N3 | 방해 금지 시간 | 없음 |
| M1 | 메뉴 관리 | 팀원 누구나 |
| M3 | 룰렛 결과 공유 | 없음 |
| E0 | 실행 환경 | 로컬 PC에서 개발, 이후 서버 배포 |
| E1 | DB | MySQL 8 (로컬은 Docker) |
| E1-1 | 데이터 접근 | Spring Data JPA (+ 통계 쿼리는 QueryDSL 또는 JPQL) |
| E3 | 화면 | 데스크톱 우선 |

### ERD 작성 중 정한 것 ([erd.md](erd.md))

| # | 항목 | 결정 |
|---|---|---|
| R1 | 삭제 정책 | 사용자, 팀, 팀 소속은 삭제하지 않고 상태 변경. 팀 삭제 = 보관(`ARCHIVED`) |
| R2 | 시각 저장 | UTC 저장, 표시와 스케줄은 `Asia/Seoul`. 날짜 값은 `DATE` |
| R3 | 반복 TODO | 생성되는 TODO는 일(DAY) 단위. 매월 31일처럼 없는 날은 말일. 평일 반복은 공휴일 제외 |
| R4 | 소급 생성 | 서버가 꺼져 있던 날의 반복 TODO는 최대 7일까지 소급 |
| R5 | 이슈 독립화 | TODO 삭제 시 그 TODO의 공개 범위를 이슈에 복사 |
| R6 | 연차 기간 등록 | 주말과 공휴일은 건너뜀. 여러 팀 소속자는 팀마다 따로 등록 |
| R7 | 알림 대상 | 알림은 알림의 팀 채널로 발송 (팀마다 채널이 다르므로 팀 접두어 불필요) |
| R8 | 이슈 검색 | MySQL FULLTEXT + ngram 파서 |
| R9 | 첨부파일 저장 | 로컬 디스크, 이미지만, 최대 10MB |
| R10 | 메뉴 삭제 | 비활성 처리(추첨 이력 보존) |

### 기획 점검에서 확정한 것 (2026-11-03)

| # | 항목 | 결정 |
|---|---|---|
| G1 | 대시보드 | 오늘 할 일, 이번 주 할 일, 오늘 부재자, 다가오는 배포 |
| G2 | TODO 이월 | 기간이 지난 미완료 TODO를 오늘/이번 주로 이월. 원래 기간과 이월 횟수를 기록 |
| G3 | 완료 취소, 기간 변경 | 둘 다 허용 (본인 TODO만) |
| G4 | 통계 집계 기준 | 주간 통계 = 기간이 그 주(월~금)에 걸친 일·주 TODO. 월간 TODO는 월간 통계에만. 완료율 = 완료 / 집계 대상 |
| G5 | 공휴일 | 슈퍼 관리자가 연 1회 직접 입력 |
| G6 | 보관된 팀 | 소속자 접근 불가. 슈퍼 관리자가 복원 가능 |
| G7 | 첫 슈퍼 관리자 | 최초 실행 시 환경변수(`INITIAL_ADMIN_ID`, `INITIAL_ADMIN_PASSWORD`)로 생성 |
| G8 | 인증 방식 | 서버 세션 (Spring Session). 매 요청마다 소속 활성 여부 확인 |
| G9 | 반복 규칙 수정 | 이후 생성분부터 반영 |
| G10 | 슬랙 발송 속도 | 같은 시각 알림은 순차 발송 (Webhook 초당 1건 수준) |
| G11 | 팀 관리자 없는 팀 | 허용. 관리자 지정 전까지 유형/채널 관리 불가 |
| G12 | 알림함 보관 | 90일 후 삭제 |
| G13 | 감사 로그 | 소속 변경, 팀 설정, 슬랙 채널 변경 이력 기록. 슈퍼 관리자만 조회 |
| G14 | 슈퍼 관리자 잠금 복구 | 다른 슈퍼 관리자가 해제. 1명뿐이면 서버 명령으로 초기화 |
| G15 | 점심 룰렛 요일 | 아무 날 가능. 금요일은 대시보드에 바로가기 노출 |
| G16 | 백업 | 로컬 MySQL 일 1회 덤프 |
| G17 | 암호화 키 분실 | Webhook URL 복호화 불가 → 팀 관리자가 재등록 |
